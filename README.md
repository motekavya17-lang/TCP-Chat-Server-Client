# TCP Chat Server and Client

A TCP-based chat application implemented using C socket programming on Linux.

## Project Description

This project demonstrates client-server communication using TCP sockets.

The server waits for a client connection, and the client connects to the server. After establishing the connection, both programs can exchange text messages.

## Technologies Used

- C Programming
- Linux / Ubuntu
- TCP/IP
- Socket Programming
- GCC Compiler
